# 在线 sensor 可视化审查

浏览器中布置场景，调用正式 GPU sensor，检查同次采样的原始数据与最终观测。服务需要保持运行。

## 启动

在项目根目录运行：

```bash
just build
just review
```

浏览器打开终端打印的本地随机端口地址，Ctrl+C 停止服务。地图默认来自 `outputs/`；可用 `just review --map-root outputs/maps` 指定目录，也可在页面上传项目格式的米制 OBJ。

## 操作

1. 加载地图，选择添加飞机或目标：按下确定 XY，拖动指定朝向，松开确认。高度通过升降按钮或 Z 输入框调整。
2. 放置飞机后点击采样。目标可选；未放置时不参与采样。
3. 打开 ToF 或 camera 的子射线距离／ID、归约结果、最终深度或外层 mask 窗口。窗口支持拖动、缩放、关闭、透明度和鼠标穿透，悬停可查看实际采样值。
4. 点击“进入视角”平滑切换到该传感器；“贴合视口”用于透明叠图，“返回总览”恢复观察位置。自由摆放的窗口不代表投影对齐。

旧窗口保留原采样编号和位姿；移动设备后需要重新采样。子射线图展示真实采样方向，有限采样可能漏掉小物体，ToF 归约也可能选择背景。相机 mask／提示框由外层开发环境生成。

当前支持一个会话、一架飞机和一个可选球形目标。浏览器只负责显示，观测由正式 sensor 计算；数据仅在显示边界从 GPU 下载。工具内的审查夹具负责捕获同次采样的内部数据，布局和识别演示也仅用于本工具。

## 检查

```bash
just check
```

统一检查包含实际 HTTP 与 GPU 采样联调；放置手势、窗口和叠图可在页面交互核查。
