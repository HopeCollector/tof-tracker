- **结果与来源审查**：独立计算两次完整 `results.json` 的 SHA-256，与 `results-summary.json` 一致；逐项核对报告中的距离、叶数、符号错误、接缝、轨迹有限差分和 CUDA 计时。核心数值模块及实际使用的轨迹工具哈希与完整运行保存值一致。
- **接缝检查复核**：四场景、两个版本的自适应场均检查所有相邻面，同级和粗细格分别统计；原始数据的面定位和选中多项式对照没有失败。测试不把两侧不同位置的导数差冒充接缝跳变，也不使用单位法向代替实际导数。
- **独立数值复算**：CPU Docker 中对八组接缝验证了面唯一性、方向与重叠范围，内部面面积满足“所有叶子表面积减外域面积，再除以二”的整数恒等式。独立 NumPy 幂基求和及显式世界导数重算最坏面，与检查器跳变结果最大差异为 `3.33e-16 m / 7.77e-15`，排除了轴序或梯度缩放错误。
- **剩余反例独立核查**：共享节点盒子在最坏节点用精确局部坐标重算，两叶值仍差约 `0.99944 mm`，定位舍入只影响约 `10 nm`。一侧接近原始几何，另一侧匹配粗格插值，支持报告中的诊断推断；未声称完整定位构建分支。
- **轨迹检查解释复核**：范围为单盒、单条 fixture、两版本 CPU/CUDA；通过表示十参数两档有限差分在给定容差内成立。末端 y 位置的误差没有随步长减半收敛，报告明确保留；接缝失败后不能用这条检查证明整场可微。采样代价和 Bernstein 地图边界检查均没有被说成连续碰撞保证。

审查中修正了 CUDA 设备编号规范化、叶子定位的 float64 离散坐标、解析盒子中轴梯度排除范围；补充 float32 对照与原生叶编号对照。最终驱动还校验原版/适配版源码哈希，并将叶编号、有限值与 CUDA 输入契约纳入集成判定。共享节点 runner 使用全新源码副本重跑盒子，数值与完整适配版盒子结果一致。
