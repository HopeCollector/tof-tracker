## 插值和接口

Catmull–Rom 可等价写成端点 Hermite 三次式：节点值共享，一阶斜率为两侧相邻节点的中心差分。三维张量积使用相同的节点混合导数，因此每个共享面上的数值、法向和切向一阶导数一致。此处 C1 指这个固定节点插值场；没有要求真实距离场在中轴或棱角处也处处可微，不保证 C2 或单位梯度。

[独立测试](esdf_grid_eval/code/verify_c1_esdf.py)没有导入实现的权重函数或格选择私有方法。参考由端点 Hermite 基函数和中心差分节点混合导数单独构造；解析平面及含交叉项二次多项式使用恰好可表示为 float32 的节点，以免把节点量化混入重现误差。

CPU/CUDA 均通过八组检查：解析重现、所有内部面、float32 精度和 float64 FD、批形状与数据所有权、闭域边界及无效输入、非法构造/查询、不同分辨率建场及 padding、持久化与损坏检测。CUDA 额外确认错误 device 被拒绝。

| 证据 | CPU | CUDA |
|---|---:|---:|
| 二次多项式世界梯度最大绝对误差 | `4.33e-15` | `3.67e-15` |
| 面上 query 世界梯度对独立 Hermite 最大差 | `1.25e-14` | `1.25e-14` |
| 两侧 query 线性外推梯度极限差 | `2.04e-10` | `2.04e-10` |
| float32 世界梯度对实际可表示位置 oracle 最大差 | `4.70e-6` | `3.75e-6` |
| float64 FD 最大差，步长 `1e-5 m` | `2.55e-8` | `2.55e-8` |

固定随机节点网格为 7×6×5，检查全部 46 个内部面，每面 3×3 内点，共 414 点。独立参考在同一世界位置分别指定左右局部多项式，值和世界梯度差均为零；实际 query 另检查面上、两侧及两侧外推极限。有限探针本身不是全域证明；共享 Hermite 节点结构给出数学 C1 依据。

闭域测试覆盖 float32/64 可表示的八个角点、六个向外 `nextafter`、NaN/±Inf；直接对含 NaN 输出的和反传，无效输入梯度仍有限且为零。端点 snap 保留法向导数。非连续输入、无 batch 输入、三类空批次、节点梯度隔离及返回副本隔离均通过。建场测试确认 0.2/0.1/0.05 m、float64 世界坐标、分块覆盖、float32 存储和 ceil padding 不扩大有效域；保存/加载位级恢复 query 值与梯度，12 类损坏被拒绝。

## 实际地图与速度口径

主任务的完整 500 柱地图为 60×60×15 m，0.2 m 节点间距，含 halo 形状 303×303×78；7,161,102 个 float32 节点，共 28,644,408 字节。当前 CPU 单线程 BVH 节点采样约 180.23 s，建图报告总计约 181.04 s。这不是历史 GPU 建场计时，不能混用。

审查者在短 Docker CPU 容器中重新读取实际地图 NPZ，逐项重算全部六组 float64/float32 误差统计，与 JSON 一致。float32 的独立几何参考使用相同的实际 float32 表示位置。每组前 128 点另在 CPU 重放，和保存的 CUDA 值/梯度最大差分别为 `1.27e-14 m`、`2.25e-13`。节点文件 SHA-256 一致。

| float64 query 样本 | 点数 | 距离绝对误差 P95 | 最大误差 | `abs(truth)>1 cm` 符号不符 |
|---|---:|---:|---:|---:|
| 均匀空间采样 | 8,192 | 18.00 mm | 72.88 mm | 5 |
| 原始盒面两侧，包含被遮蔽面 | 10,981 | 31.65 mm | 77.93 mm | 144 |
| 柱体内部 | 1,000 | 72.39 mm | 82.72 mm | 10 |
| 重叠内部 | 156 | 52.43 mm | 84.98 mm | 0 |
| 近地面 | 1,024 | 11.35 mm | 47.25 mm | 2 |
| 共享节点 | 2,005 | 0.0000984 mm | 0.000227 mm | 0 |

合计 23,358 点 P95 为 31.52 mm，最大 84.98 mm。该合计偏重近表面与内部，不能解释成全空间均匀统计。按真值另分组：7,783 个内部点 P95 为 52.49 mm；其中 **143 个真值小于 -1 cm 的点，插值值大于零**。15,329 个自由空间点 P95 为 20.21 mm，另有 18 个真值大于 1 cm 的符号不符点。剩余点在真值零面。最大正向误差也是 84.98 mm，说明偏差不全是保守低估。

实际图 384 个面点的 float64 两侧外推梯度差为 `1.06e-11`，位置 FD 最大差 `2.19e-9`，验证对象仍是插值场的导数；这没有测试其梯度与最近 mesh 法向的一致程度。原始几何节点和插值误差也分开：共享节点最大误差约 `2.27e-7 m`，不代表格内误差同级。

速度表的实现口径是 GPU 常驻地图和位置、float32、同步 Python wall time，2 次热身后 10 次测量。10 万点 query / query+位置 backward 中位数约 0.799/1.169 ms，262,144 点约 1.718/2.402 ms；不含磁盘读取、传输、mesh、轨迹解码、代价或优化。计时没有记录逐次原始时间，审查核对的是计时代码及汇总口径，不声称独立复测性能。

## 几何和积分实现的只读审查

mesh 路径在轴对齐盒并集上先去内部面，再建立 BVH；ground 显式扩展为占据半空间语义，远端 slab 面通过外露地面 witness 距离上界排除。直接输入任意 mesh 的闭合、绕序和顶点流形检查，不等价于自交/布尔正确性检查；无自交、无重叠嵌套组件仍为调用前提。double 投影加三边残差重算仍依赖第三方 BVH 的选面和边/顶点符号，不是精确算术全局保证。C ABI 数据所有权、异常边界、close/query 锁与库生命周期未见阻塞。

当前全图参考的矩形距离运算独立于三角 BVH，但矩形外露边界准备采用同一轴对齐盒模型和相近的覆盖相减机制；不能称完全独立的通用布尔 oracle。mesh 测试中的解析交叉实体、触面/包含、ground 内部幅值等补充了这部分覆盖。

最初建图后，第三方头文件另加入无命中、非法特征和非有限伪法线的异常保护，检查发生在索引最近面之前；成功有限查询的运算未改。主任务用最终共享库重算 2,048 个已有节点，其中 67 个属于 halo，float32 位模式（含零的符号位）全部一致。审查读取了 `native-library-node-recheck.json` 并核对保护代码；这次抽检不是完整重建，也不把最终库 hash 当成原建图库来源。

[积分报告](PATH_INTEGRAL_REPORT.md)的 degree≤45 场值、degree≤90 平方代价及 Bernstein 系数均值积分成立。通常横穿条件下，C0 使相邻积分的移动边界项相消，允许一阶反传固定已求出的穿格时刻；近切触与根合并仍需明确拒绝或另行处理。GL48/64 对照共享穿格 partition，独立于场多项式构造，但不独立证明数值根完整。

审查者另从 raw Bernstein 数组重算六组积分，与 JSON 最大差 `2.78e-17`；再用不复用穿格 partition 的整曲线 Simpson4096 通过公开 query 复查，代价值最大差 `7.43e-12`，18 个系数梯度最大差 `2.05e-8`。十参数 FD 数组重算的最大误差为 `2.27e-11`，源哈希匹配。该独立有限求积仍不是根隔离或连续碰撞证书。首轮落面退化族 FD 的拒绝记录保留，普通六组成功不覆盖该退化族；平方目标也不是正式避障损失。
