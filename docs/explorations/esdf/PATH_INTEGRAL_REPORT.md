# 分格多项式路径积分：小实验结果

**在六组确定性 CPU 小场案例上，曲线穿格分段、逐段多项式积分，以及对曲线系数/终端状态/T 的梯度链路已经跑通。** 这证明特定多项式代价的计算路线可行，不表示任意避障损失可以无采样求积分，也没有把它加入正式 ESDF API。

运行入口与完整算法边界见[实验说明](../../../experiments/esdf_grid_eval/README.md)。本轮原始输出是 `outputs/esdf_grid_eval/path-integrals-20261018-v2/`；[紧凑摘要](path-integral-summary.json)保存源文件、镜像、原始 JSON/NPZ 的 SHA-256。环境为 Python 3.12.3、NumPy 2.5.4、Torch 2.9.1+cu128，实际仅运行 CPU，Torch 单线程；没有测试积分吞吐。

## 验证了什么

规则域 `[-1.5,1.5]^3 m`，间距 0.25 m，节点 float32，查询和积分计算 float64。三个输入通过正式 `fit_trajectory` 拟合五次曲线，采用归一化 `u=t/T`。两种场分别为已知二次标量函数和球 SDF 的节点样本。**积分的对象是插值后的场**；球节点案例不声称其曲线积分等于解析球 SDF 的积分。

示范代价是 `J = T ∫ 0.5*(F(p(u))-0.1)^2 du`，不是最终避障 penalty。每段用 Catmull–Rom 64 节点组合 Bernstein 多项式，最高 45 次；平方后最高 90 次，系数均值直接给出单位区间积分。

| 曲线 | 每个场的分段数 | 几何特征 |
|---|---:|---|
| three_axis_quintic | 17 | 三个轴均移动、多面穿越 |
| return_across_faces | 25 | 同一格面多次穿越，去程与回程分别分段 |
| constant_z_off_faces | 13 | 一个坐标恒定，另两轴穿格 |

六组全部满足预设数值容差，主要最大绝对差如下：

| 对照 | 六组最大差 |
|---|---:|
| Bernstein 积分 vs 公开查询 GL48/64 的代价值 | `4.17e-17` |
| 同两条链路的终端 p/v/a + T 梯度 | `4.69e-16` |
| 18 个自由系数梯度 vs 公开查询 autograd | `1.67e-16` |
| 十参数梯度 vs 中心有限差分（步长 `1e-6`，每次重求根） | `2.27e-11` |
| 二次场积分 vs 独立解析低次闭式积分 | `5.79e-16` |
| 相邻分段同一穿格点的插值值差 | `7.78e-16` |

代价值对照阈值 `2e-10`、梯度对照 `2e-9`；参数 FD 阈值为 `2e-7 + 2e-5*abs(FD)`。这里的误差是计算路线之间的一致性，**不是插值场相对几何真值的距离误差**。独立二次函数 oracle 使用解析函数，避免只让两个实现互相自证；一般球节点场的对照则仅验证该离散插值定义。

GL48 在精确算术下可积分最高 95 次多项式，因此作为分段独立对照足够覆盖 degree 90。它仍对每段作有限点评估；主算法的 Bernstein 系数积分和对照求积不能混称。两条路径共享数值分段，所以该对照独立于场多项式构造，不独立证明根完整性；二次闭式 oracle 和重求分段的 FD 提供当前 fixture 的额外证据。`exp(-F/0.4)` 只做 GL32/64 数值值/梯度比较，本轮观察到收敛；没有解析 exp 积分实现或全域误差保证。

## 退化输入、失败与限制

首轮第三条曲线整个 z 坐标都在一个格面上。基线可选一致侧求值，但终端参数 FD 扰动进入近切触情形，数值求根保护明确拒绝，运行停止；记录保留在 `outputs/esdf_grid_eval/path-integrals-20261018-v1/failure.json`。没有放宽根残差/切触阈值。第二轮将普通 FD fixture 的 z 移到 0.375 m，另以切触和越域案例确认拒绝路径。

根求解采用数值多项式根，不是严格根隔离；另通过坐标极值检查每段保持在所选格内，也使用数值根。接近切触/近多重根明确拒绝，不能把该检查当作数学证书，更不能将其转述成连续碰撞保证。

穿格时刻不参与 autograd，依赖通常横穿条件下 C0 场的移动积分边界项相消；有限精度误差由 FD 核对。未覆盖任意切触/根合并、任意尺度、长轨迹、大图、非多项式代价的解析积分、学习梯度、动态地图或 GPU 积分速度。历史自适应八叉树实验从未实现过整轨迹解析损失；本次是新规则场上的独立示范。
