# 独立审查：曲线分格指数积分

本轮审查未发现阻塞实验交付的问题。以下结论限定于当前源码、已保存的 C1 场和固定 120 条曲线：分格求积降低了同场时间离散误差，但更新曲线后约 0.75 秒的 CPU 分格成本是明确的性能限制。未验证在线优化器、避障成功率或连续碰撞保证。

## 对象与数学范围

当前实现的目标是同一个 C1 距离场上的归一化时间均值

`J(c) = ∫₀¹ exp(-(F(Σₖ cₖ uᵏ)-1.2)/0.6) du`。

`integrate.py` 先数值求曲线与规则格面的交点，再在每个时间段使用 GL4/8/16/32 求积，批量调用公开 `ESDFGrid.query`。它没有解析积分指数函数，也没有构造并精确积分有限阶的指数多项式。曲线系数对应 `u=t/T`；目标不另乘 T。时长影响若存在，应来自边界状态到系数的映射。

分格从已有 `split_curve` 适配，使用数值四次导数根划分单调区间，再对与格面方程异号的区间二分求交点；仍保留近内部切触拒绝、近重根拒绝、相邻根合并与范围容差。这些检查不是区间算术证书，不能证明任意输入下已枚举全部根，也不能作为连续碰撞或最小净空算法。

第一轮直接复用旧 splitter，在真实地图 curve 1 停止；进一步诊断发现 20 条 float64 曲线受端点驻点和端点二重根的数值碎片影响。失败日志及中间适配失败均保留，没有跳过曲线。最终实验适配把距 u=0/1 不超过 1e-10 的驻点归为端点，仅当端点格面方程值处于 `32·eps64·max(1,Σ|系数|)` 内时归零，并记录原值与容差。二分替代五次伴随矩阵根，避免端点二重根产生虚假的内部根。真正内部的近切触仍拒绝；这不是扩大成任意切触均受支持。

审查确认此版本未取消最终区间极值覆盖检查。不过该检查和单调区间构造共享数值导数根，因此不能称为独立的根完整性证明。最终 integrator SHA256 为 `c58e20265b058e258529801ad25daa5a75d38165c2c02f80d3ebaf2efe27ab8f`。

## 源码审查

已只读审查 `integrate.py`、`reference.py`、已有 `path_integrals.py` 和 `tests/verify_esdf_curve_integral.py`，未修改实现。已确认：

- 分格前只将实际输入系数复制一次到 CPU double；float32 必须按其实际系数重新分格，不能直接复用 double 分格后再改 dtype。
- plan 保存原系数并检查形状、设备、dtype 和数值是否一致；更新曲线后须重新分格。根、plan 打包、上传不属于缓存 plan 的积分调用。
- 任一曲线分格失败会使整个 batch 抛出带曲线索引的异常；非有限积分结果不会被当成零代价。
- 公共场查询仍按实际位置选择 cell。保存的 `cells_xyz` 用于诊断，没有强制外推某个 cell 多项式。
- `torch.equal`、有限性判断和公开 query 的同步成本是真实执行成本；计时不能将此实现称为未检查的纯 kernel。
- 独立数值参考使用均匀复合 Gauss，不共享被测 face roots。空间导数由公开场得到，再用独立五次曲线终端敏感度与 `u^k` 分别累计九个末端参数和十八个系数导数。无效样本会使整条曲线的代价及梯度为 NaN。
- 参考每级保存值和两类梯度，分别要求连续两次满足精化差准则；未收敛行不删除。相邻级差只是观测误差，不是严格积分误差界。

根和区间长度 detach 的依据是：普通横穿时，相邻**精确积分**的移动边界项因场连续而抵消。有限阶 Gauss 规则的节点本身随曲线移动，所以 detach 后的 AD 不一定等于该有限规则重新分格后的精确导数；应通过求积阶数收敛和重新分格 FD 检查这项差异。测试没有将固定旧 plan 的 FD 冒充更新曲线后的 FD。

## 独立 CPU 闭式检查

审查者另在 Docker CPU 中执行了 `outputs/esdf_curve_integral/review_closed_form.py`。它使用三轴法向均非零的 dyadic 平面场，所有节点值可由 float32 精确表示，避免将节点舍入误差混入闭式判断。两条直线分别跨 9 格和 4 格，沿曲线的指数斜率为 −1.71875 和 0。

参考由独立 long-double 矩级数计算：

`Mₖ(B)=Σⱼ Bʲ/[j!·(j+k+1)]`，`J=exp(A)M₀(B)`，`∂J/∂cₖ=−n·exp(A)Mₖ(B)/0.6`。

它同时给出全部 18 个系数导数，包括高次系数当前为零时的非零导数；没有使用被测分格或公开场 query 作为参考。最终版本 GL8/16/32 的代价最大误差不超过 8.88e-16，系数梯度最大分量误差不超过 1.78e-15。两条曲线、18 个分量、两个步长的中心 FD，每次正负扰动均重新分格，最大差为 3.45e-10。第二条曲线为切触反例的 batch 确实整体拒绝，并报告 curve index 1。

最终证据为 `outputs/esdf_curve_integral/review-closed-form-monotone-20261018.json`，对应上述 `c58e2026…` integrator；初版 `72612dba…` 的 `review-closed-form-20261018.json` 保留，未覆盖或冒充最终版。独立 probe SHA256 为 `90b5353713f135a1cbe32f3d91a67248a998711616f910ed84794a971d32a3d7`。这是普通横穿曲线上的独立公式验证，不能代替真实地图精度和实际端到端耗时测量。

研究 agent 另执行了完整 CPU 检查，最终版本记录在 `outputs/esdf_curve_integral/cpu-check-monotone-20261018/`：包含非线性场独立均匀求积、18 系数 FD、初末 p/v/a 加 T 共 19 参数 FD、float32 自己分格和拒绝路径。几何 agent 的独立参考检查记录在 `outputs/esdf_curve_integral/reference-cpu-verification.json`。本审查已读取这两组实现与结果，不把其他 agent 的运行写成审查者独立重跑。

## 真实地图原始数组复算

审查者在 Docker CPU 中运行独立 NumPy 脚本 `outputs/esdf_curve_integral/review_raw.py`，读取完成的 v3 `comparison/raw.npz` 和 `results.json`；没有导入被测积分或统计函数，也没有重跑 GPU 计时。输出为 `outputs/esdf_curve_integral/review-raw-v3-20261018.json`。逐项核对了：

- 139 个原始数组全部有限，原 120 条系数与上轮输入逐位相同；7 项运行源码、地图 metadata 和 samples 哈希与当前文件一致。
- 原 double 参考及实际 float32 系数提升后的参考，每级代价、9 参数和 18 系数梯度变化量、阈值与逐行 mask 均可由 raw 复算；末级连续两次通过的数量均为 120/120。
- 两种 dtype 各 3533 段，覆盖全部曲线，逐条区间从 0 到 1 严格相接、长度为正；GL 节点在区间内、权重为正，每条权重和为 1。每段另取 5 个内部时刻，以独立幂次和求位置，均位于记录的 cell 内。这是样点一致性检查，不是全段或根完整性证书。
- 全部同场代价、p/v/a 三组梯度、18 系数梯度和辅助 mesh 指标与报告统计一致。向量范数、点积和角度统计都先提升到 float64，避免 float32 的 arccos 舍入失真。
- 固定序号 7、112 的两档步长、两种 GL 阶数 FD 差与保存 AD 一致；`h=1e-5` 的最大分量差为 `1.51e-10`。这里独立复算的是已保存 FD 证据；重新运行所有扰动由驱动完成。
- 每次计时的分项之和等于该次 total；中位数及 P95 与保存结果一致。分别取分项中位数后不必再相加等于 total 中位数。

GL8 的 loss 和末端 9 参数梯度均在 120/120 条上比固定 30 点更接近同 C1 场参考。GL8 与 GL32 的最大代价差为 `1.51e-14`，但最后一次独立参考加密的最大代价变化为 `3.00e-10`，9 参数 / 18 系数梯度 L2 变化约 `1.15e-6 / 2.38e-6`。因此 GL8/16/32 的细小排名已超出本次参考的辨别能力；不能宣称真实积分误差已被证明达到 `1e-12`。

对辅助 mesh 数值积分，GL8 的 loss 只有 95/120 条比固定 30 点更近，25 条变远。分格不改变 0.2 m 场的空间近似，时间误差与空间误差也可能抵消。原 mesh 代价 mask 为 120/120，梯度为 116/120，保留 866 个 tie 样点；主结论不以未收敛 mesh 梯度为真值。

独立输出还保留了预先指定的序号 7、112 两条曲线的四种代价，没有按结果重选；报告所引例子与原始数组一致。

## 性能口径与剩余覆盖

120 条实际 float32 已有系数的中位耗时，固定 30 点为 `1.389 ms`；GL8 每次重新分格为 `758.805 ms`，其中 CPU 分格约 `756.023 ms`，未变曲线复用驻留 plan 时为 `1.412 ms`。新曲线计时包含系数复制、CPU 根求解、plan 准备上传以及公开 query 的检查与同步；不能以缓存数字声称更新参数的优化循环接近固定 30 点速度。实现内检查计入，计时之后的实验用有限梯度断言未计入。

完整初末状态拟合到末端 9 参数反传已另列，没有用已有系数范围冒充。已有系数的 float32 精度表使用 double 拟合结果转 float32；完整链计时则从 float32 初末状态重新拟合，二者不能视为逐位相同输入的完整链精度证明。固定 T 的真实地图测试不覆盖时长梯度；时长仅在小场参数链 FD 中检查。

每项只有 2 次预热、5 次测量，输入曲线数值固定；fresh 范围每轮确实重新构造计划。这是该批次的预热 wall time，不能推断冷启动、随机训练分布、长期尾延迟或参数优化的收敛速度。没有重跑 GPU 来选择更有利的计时。
